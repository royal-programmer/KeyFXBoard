# Before you finish

### After setup

1. Key FX Board may open, or sit in the **system tray**. Double-click the tray icon to open the window; a single click mutes.
2. First launch can take a few seconds while factory piano samples are prepared.
3. **My sounds** — drop your own audio files via Packs → Open My sounds folder, then choose them on Profiles.
4. **Instruments** — start piano (and later drums) from the Instruments page; only one instrument runs at a time.

### Privacy

A keyboard hook exists only to play sound. Nothing you type is stored or sent. Logs never contain keystrokes.
