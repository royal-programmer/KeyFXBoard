# Readme

- After setup, Key FX Board opens (or sits in the tray). If the window is hidden, double-click the tray icon.
- First start can take a few seconds while factory piano samples are created.
- Custom samples: `%AppData%\KeyFXBoard\custom-samples`
- Getting started guide is installed next to the app as `GettingStarted.html`.

Privacy: we do not record keystrokes. The hook only triggers sound.
